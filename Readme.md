# MyTube

A full-stack YouTube-inspired video sharing platform.

## Repository Structure

📁 mytube/   → Frontend (Next.js + React + TypeScript)

📁 server/   → Backend (Express.js + MongoDB)

## Features

✔ User Authentication
✔ Video Upload
✔ Search
✔ Watch History
✔ Watch Later
✔ Subscriptions
✔ Personalized Theme
✔ Premium Plans
✔ Responsive UI

## Tech Stack

Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

## Installation

### Frontend

cd mytube
npm install
npm run dev

Runs on:
http://localhost:3000

### Backend

cd server
npm install
npm start

Runs on:
http://localhost:5000
